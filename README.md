# dzbot SDK

Build your own DayZ Discord bot or website on [dzbot](https://dzbot.de): players, wallets, the shop, tickets,
the kill feed and every other dzbot feature through one typed client, plus Sign in with dzbot, webhooks and live
events.

- [`packages/sdk/`](packages/sdk) — `@dzbot/sdk`, the hand-written layer (client, OAuth, webhooks, live events, event types)
- [`src/api/generated/`](src/api/generated) — the generated client behind `@dzbot/sdk/api`, every endpoint of the API

Documentation: **https://developers.dzbot.de/sdk/** · A bot to start from: https://github.com/siemendev/dzbot-starter

This repository mirrors the code dzbot runs itself; it is developed in dzbot and synced on every release. Issues
are welcome here; pull requests are ported by hand.
